🍔 Foodie – Food Delivery App

Foodie is a modern food delivery app project with a premium Purple and Baby Pink theme.

✨ Features

- 👤 Customer section
- 🍽️ Restaurant section
- 🛵 Delivery Partner section
- 🥗 Food categories and restaurant menus
- 🛒 Shopping cart and checkout
- 💵 Cash on Delivery (COD) demo
- 📱 Responsive mobile-friendly design
- 💜 Purple and Baby Pink UI
- 🌐 Website starter project

🛠️ Technologies

- HTML
- CSS
- JavaScript
- GitHub Actions

🚀 How to Use

1. Open the repository on GitHub.
2. Upload the project files.
3. Open the "web" folder.
4. Open "index.html" to view the frontend code.

⚠️ Important

This is a starter demo project. Real user accounts, restaurant management, delivery tracking, database storage, and live online payments require backend integration and secure configuration.
